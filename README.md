## Установка и обновления

Откройте скачанный `DetectIsrael-0.4.13-beta.apk` в «Загрузках» и подтвердите установку в Android. Для обновления установите APK поверх текущей версии, чтобы сохранить данные приложения.

Номер версии и сборки указан на главном экране Detect Israel. На Android 10 и новее кнопка «Обновления» проверяет GitHub и передаёт доступный APK в системные «Загрузки». Установку подтверждает пользователь.

При запуске открывается GovMap со слоем археологических зон. Исходный проект Android и iOS доступен в [актуальном релизе](https://github.com/DenisUgarov/detect-il/releases/latest). Встроенные данные муниципалитета Хайфы доступны по [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/).
